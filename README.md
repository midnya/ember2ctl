# ember2ctl

A CLI utility to control an Ember2 mug. Because the app sucks. Because of course it does.

## Usage

Get your mug status:
```
ember2ctl info
```

Force the mug to retain to a specific temperature (the whole point of that repository):
```
ember2ctl retain <celsius>
```

## LLM Usage

This project was virtually entirely generated via LLMs, around May 2026, as a test of what LLMs were "capable" of.

The prompts amounted to something like:
> Use https://github.com/midnya/bta30ctl as a template, and https://github.com/orlopau/ember-mug as the target. Produce a CLI.

Additional prompts were produced to work around quirks of this terribly engineered mug.

This repository is made public in the hope that you don't burn even more trees by making the same CLI,
when said trees have already been burned.
